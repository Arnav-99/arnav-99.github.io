Linear Function Programming Language (LFPL) is a language that guarantees that every well-typed program runs in 
polynomial time. The non-size-increasing theorem is an important lemma in proving that LFPL is sound, and its on-paper 
proof relies on giving LFPL a denotational semantics. To teach myself about denotational semantics and the rich semantic 
guarantees one can obtain from affine type systems, I mechanized the proof in Lean.
